Datei wurde extern geändert

Die geladene Datei wurde auf der Ablage geändert, während der Editor ungespeicherte Änderungen enthält. Das automatische Neuladen ist ausgesetzt.

Achtung: Bei „Datei neu laden" gehen die eigenen ungespeicherten Änderungen verloren.

Neu laden verwirft Änderungen

Der Editor enthält Änderungen, die noch nicht als Kopie gesichert sind. Beim Neueinlesen der Datei gehen sie verloren.
